# Board Documents

This directory contains one document per packaged board.

Each board document states the current evidence level, upload behavior, battery and power-path model, secondary-bus truth, BLE/LFCLK status, and major caveats.

**Related**: clone ProMicro / single-cable USB facts are summarized under **`docs/USB_SINGLE_CABLE_PLAN.md`** (pitfalls + bootloader layout); dual CDC + USB GDB IDE integration tasks live in **`docs/DUAL_CDC_AND_USB_DEBUG_ROADMAP.md`**.
